# Brand

## Product Name

**Max**

**MAX:** Managed Agent eXecution

Max is the brand. Short, keyword-shaped, the thing you say out loud: CLI, toasts,
dashboard short references, and eventually a home personal-assistant wake word
("max all the things," take it to the max). The coding factory is the current
surface; the longer dream is Max as the household keyword. Do not expand charter
to chase that dream early — see project charter / Platform vs Payload.

## Long Form (acronym scaffolding)

**Maxwell**

**MAXWELL:** Managed Agent eXecution With Event-Linked Logic

Maxwell is a searchable full form behind Max — acronym expansion for README
titles, public repo naming, and first introduction — not a separate mythos.
**Maxwell's demon is not the brand story.** It was post-hoc lore; it has no
operator pull. Do not subtitle the product "Maxwell's Daemon" (that name is
already a well-known MySQL CDC tool from Zendesk). If disambiguation is ever
needed: one README line, then move on.

## Positioning Notes

- Lead with **Max**. That is the identity.
- Use **Maxwell** only where a full form helps: README title, public repo
  slugs (prefer qualified, e.g. `maxwell-automations`, not bare `maxwell`),
  first introduction copy. Dashboard first paint stays **Max** — the shipped
  UI (tab title + wordmark) already matches. Never as demon mythology.
- CLI: primary bin is `max`, with `lca` kept as a permanent alias. Implementation
  identifiers (`LCA_*`, `@lca/*`, `X-LCA-Control-Token`,
  `~/.cursor-local-automations/`) stay unchanged.
- Price Cursor "Max Mode" as the real short-name collision in IDE copy; do not
  let the Zendesk CDC tool reopen naming once Max is locked as the brand.

### Visual lockup (optional)

**Max.Well** — the full name as a period split: short brand + "well." Reads as Maxwell without demon lore; works as a logo mark or splash. Prefer sparingly (title treatment), not as the CLI or everyday noun (that stays **Max**).

### Rejected / wrong lane

- "Maximize your product lifecycle with Maxwell" — SaaS lifecycle tone; fights the reference-implementation posture and the home-keyword dream. Leave it.
