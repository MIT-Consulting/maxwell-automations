# Max skills

Skill bundle for **Max** (Maxwell) — Managed Agent eXecution With Event-Linked
Logic. Tagged in lockstep with
[`maxwell-automations`](https://github.com/MIT-Consulting/maxwell-automations).

**Clones and forks welcome. Contributions are closed.**

## Install

1. **Cursor plugin** — import this GitHub repository as a plugin (auto-refresh on push).
2. **CLI** — from a Max checkout: `max skills install` (copies into `~/.cursor/skills/`).
3. **Fork** — clone and add your own skills; pin to a release tag if you depend
   on daemon contracts.

Minimum compatible daemon: the same `vX.Y.Z` tag as this bundle.
